# Site Oficial – Dra. Michele Carneiro

Este repositório contém o site institucional da Dra. Michele Carneiro, nutricionista integrativa funcional.

O site apresenta informações sobre consultas, serviços, programas terapêuticos, e-books e conteúdos educativos relacionados à nutrição integrativa, fitoterapia, aromaterapia e saúde intestinal.
